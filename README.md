# QuantPilot A股量化研究平台

这是一个面向 A 股研究的网页工具，包含股票池、实时行情、策略实验室、历史回测和个股详情。

## 本地运行

需要 Node.js 20 或更新版本：

```powershell
node server.js
```

浏览器打开 `http://127.0.0.1:8080/`。

## 公网部署

支持 Cloudflare Pages：静态页面由 Pages 托管，实时行情、股票目录、个股详情和回测 API 由 Pages Functions 运行。GitHub 连接设置为构建命令 `npm run build`、输出目录 `dist`。详细配置见 [DEPLOY.md](DEPLOY.md)。

## 数据说明

实时行情来自腾讯公开行情接口，个股历史 K 线和公告来自东方财富公开接口。回测由服务端代码执行，不依赖大模型 API。当前不连接券商，也不会自动下单。

历史回测和因子收益研究优先使用东方财富前复权日线；东方财富暂不可用时，按两年区间分段回退到腾讯前复权日线，并在报告标明实际数据源。实时快照继续使用腾讯行情。回测信号在收盘后计算，模拟成交使用下一交易日开盘价并计入佣金、印花税和滑点；请求的结束日若尚未完整收盘，会截到最近一个完整交易日。结果同时展示同区间买入持有基准和超额收益。

因子研究输出训练期、样本外期、Rank IC、分组持有期收益、成本后多空收益、换手、收益覆盖和多个前瞻期的衰减诊断。因子截面按 MAD 规则缩尾并统一方向；数据异常会记录在报告中，极端涨跌只告警、不自动删除。最高组减最低组是预测能力研究统计，A 股融券限制使其不代表可直接执行的组合。

当前没有历史成分股快照、退市股票历史、财报公告时点数据、涨跌停/停牌成交约束或容量模型，因此仍可能有幸存者偏差，模拟结果也不等同于真实成交表现。公开行情接口的字段、限流和可用性由上游服务决定。
